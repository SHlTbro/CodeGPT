从本机开始

  1. 安装 Python 3.12+，解压源码到短路径。
  2. 双击 local-codebase-mcp/setup.bat，添加项目并保持只读。
  3. 连接 ChatGPT 时，按页面教程配置 ngrok；Cloudflare 临时地址为备选。

现有公网 MCP 没有用户身份认证。私人源码和写权限应先落实可信访问限制，固定地址不能代替身份验证。安全边界 ↗
