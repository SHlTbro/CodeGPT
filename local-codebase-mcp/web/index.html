配置 ngrok 约5分钟

  1. 注册或登录

    打开 ngrok 注册 / 登录 ↗，按提示验证邮箱并进入 Dashboard。

  2. 下载 Windows 程序

    下载 ngrok for Windows ↗，解压 ngrok.exe，放到本项目目录，再点。

  3. 复制 authtoken

    打开 Your Authtoken ↗，找到 Authtoken 并点击 Copy。请勿复制 API Key。

  4. 凭据只保存在本机，不会回读。

    复制了整行命令？

    也可粘贴不带引号的 ngrok config add-authtoken 命令。
