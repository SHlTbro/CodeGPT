# 访问与权限边界

Setup 控制面只监听 localhost 的独立端口；隧道目标为 MCP，不转发配置页面/API。Core 保留项目注册、敏感文件过滤、路径/链接越界检查、字符预算和项目级受控写限制。读过的文本会传给调用客户端，不能宣称代码从不离开电脑。

公网 MCP 当前没有最终用户身份认证。知道 URL 的人可能调用登记项目工具；固定域名、随机 URL 和 ngrok Authtoken 都不是访问身份。只读也不防止敏感内容泄露。无认证验收仅登记无敏感合成项目，关闭写与 Agent。

私人项目远程接入必须另外证明可信访问限制。官方 Secure MCP Tunnel 可作为最小方案候选，通过平台账户/组织/工作区权限控制访问；在目标账号上真实验证前不宣称已支持，也不增加 CodeGPT 自研 OAuth。

Agent 默认关闭；模型选择/设置保存不发起推理。尚未证明的执行模式拒绝启用，未经验证公网调用不能启动 Codex。Core 不依赖 Codex 登录、VMware 或自研 OAuth。

配置、密钥、日志、`.setup`、模型上下文、数据库、备份和虚拟环境不进入 Git。备份也必须限制目录读取权限。遇到凭据披露，由账号 owner 撤销旧值再只在本机界面保存新值；工具不会自动撤销账号凭据。
